# DeathNotificationLib Data

**DeathNotificationLib Data** is an optional standalone dependency package for [DeathNotificationLib](https://www.curseforge.com/wow/addons/deathnotificationlib).

It contains precomputed heatmap data generated from collected death records.

### What This Package Contains

* Precomputed death heatmap datasets for Classic Era Hardcore and TBC Anniversary Soul of Iron servers

### Who Should Install This

* Install this package together with **DeathNotificationLib** only when using standalone packages.
* If a dependent addon already embeds DeathNotificationLibData, this package is optional and does not need to be installed separately.

### What This Package Does Not Do

* No UI
* No slash commands
* No standalone player-facing functionality without DeathNotificationLib
